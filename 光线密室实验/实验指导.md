# 光线密室 实验指导文档
## 一、实验简介
本项目实现简易光线追踪光学交互小游戏。用户拖动镜子、棱镜，改变光路，让光线打到接收器，触发机关开门。
基础功能：镜面反射；拓展功能：棱镜折射、色散分光。

## 二、环境（Linux Ubuntu 虚拟机）
安装依赖命令：
sudo apt update
sudo apt install build-essential cmake libsfml-dev

## 三、编译运行步骤
1. 进入项目根目录（光线密室实验）
2. cmake -B build
3. cmake --build build
4. ./build/light_room

> 注意：虚拟机需要图形桌面或者 X11 转发，否则 SFML 窗口无法打开。

## 四、开发顺序建议
阶段 1：保证项目正常编译，窗口弹出。
阶段 2：A 完成射线求交 + 反射，拿到基础光路。
阶段 3：B 完成鼠标拾取、拖拽镜子。
阶段 4：C 画出光路、镜子、接收器、门。
阶段 5：联调测试，验证“光线命中接收器开门”。
阶段 6（加分）：加入棱镜折射、色散分光效果。

## 五、原理要点
1. 向量几何：点积、叉积、归一化
2. 光线追踪：射线求交，取最近交点
3. 反射定律、斯涅尔折射定律、全反射
4. 事件驱动交互：鼠标按下、拖动、松开
5. 实时渲染循环：每一帧重新计算光路、重绘画面
