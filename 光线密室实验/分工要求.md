# 光线密室实验 — 三人分工要求
项目目标：C++ + SFML 实现可拖拽光学元件、实时光线追踪，光线击中接收器开门。

## A｜算法物理组（RaySolver）
负责：光线追踪核心、向量几何、求交、反射、折射、光路递归计算。
需要补全的 TODO[A]：
1. Vec2 归一化
2. 射线与线段求交
3. 反射向量计算
4. 斯涅尔折射 + 全反射判断
5. 遍历元件、寻找最近交点、分支处理镜子/接收器/棱镜
输出：每帧光路点列表、是否命中接收器。

## B｜交互与场景组（SceneController）
负责：关卡配置、鼠标拾取、拖拽平移/旋转、坐标转换、状态管理。
需要补全的 TODO[B]：
1. 屏幕坐标到世界坐标转换
2. 包围盒拾取元件
3. 拖拽更新元件位置或者旋转角度
4. 配置各个关卡初始元件

## C｜渲染展示组（Renderer）
负责：画面绘制、光路可视化、元件样式、门动画、美化效果。
需要补全的 TODO[C]：
1. 绘制镜子、棱镜、接收器，区分接收器点亮状态
2. 绘制连续光路，设置颜色粗细
3. 绘制门，实现开门、关门视觉效果

## 协作约定
1. 接口固定，不要随意修改结构体和函数签名；
2. 使用 Git 同步代码；
3. 先保证基础反射关卡跑通，再拓展棱镜、色散加分功能；
4. 最后一起联调、写实验报告、准备演示。
